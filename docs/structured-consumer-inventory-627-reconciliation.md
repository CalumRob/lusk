Treat the shared Habitat indicator-page consumer as **failing/unresolved**, not static or migrated, until this is fixed and rechecked. The failure is a common theme-metadata path, so the other Habitat page routes are at risk even though each was not individually opened.
- **Branch correction (not deployed):** the page now validates that every scalar contract is bound to a declared page, filters to scalar-family pages before validating/using the scalar cohort reader, and leaves contracts on non-scalar pages such as `prix_m2` for their declared family path. The routed `part_passoires` regression mounts the production Habitat metadata, asserts a cohort request, and forbids static Habitat fact loading. This branch passes that test and the full app suite/build; the public site remains on the old bundle, so the observed production failure remains unresolved pending normal review/merge/deployment and post-deploy browser verification.
- Global map: `CarteView.vue` reads the static payload for layer definitions and can overlay a selected registered scalar from the cohort API. Other numeric shapes continue to read static payload rows. A per-key layer/request trace has not been captured.
- Non-browser: `pipeline/R/modeles_lecture.R::publier_modeles_territoire_depuis_json()` reads all six `indicateurs_<theme>.json` files to build territory read models. **Every key below therefore has a confirmed static-input dependency in this producer. Per owner decision on 2026-10-07, this dependency remains UNRESOLVED; no rollback-retention rationale is approved.** The read-model output is also used as the fiche's atomic identity/metadata/presentation bootstrap; the exact need for its numeric columns after theme API acquisition has not been separated yet.
- Dispositions: `migrated` requires consumer-specific evidence; `retired` requires an owner decision; `retained` requires a named consumer/reason and explicit owner approval. `unresolved` is the correct state when evidence or an owner decision is missing. Producers and tests are not counted as additional product readers, but active producer inputs are recorded.
