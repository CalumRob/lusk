## Current contract and what the census means

- Current API contracts are defined by [API ENDPOINTS](../api/ENDPOINTS.md) and [ADR-0040](adr/0040-unified-semantic-serving-backend.md): `GET /api/resources`, semantic `POST /api/resources/read` / `read-batch`, territory search, health. Semantic batches prevalidate and run in one read-only repeatable-read snapshot (maximum 12 items, bounded work/output); selected comparison has a typed bounded membership list.
- The producer-derived catalogue currently accounts for **62 declared theme/key pairs: 33 retained identities and 29 excluded legacy accessibility declarations**. The source metadata has **45 `indicator_pages` entries**, of which 14 are the superseded Mobility accessibility pages. PR #835 omits those 14 from the app-owned catalogue and grouped indicator search, which now list 31 retained pages; the producer declarations remain. This is only that consumer boundary: direct URLs, old metadata/payloads and other readers are not retired. Recompute as documented in the broader inventory; never hand-maintain these counts.
- The supported resource set additionally includes four typed readings and AEDAR. Catalogue presence is declaration/accounting evidence only; it is not a live publication or consumer-parity assertion.
- This checkout's frontend is not fully migrated to the current API contract. `TerritoireView.vue` still requests `/themes/{theme}/facts` and old comparison paths for its theme acquisition; ordinary registered scalar consumers have a separate, unmerged migration to semantic catalogue/read-batch reads (see the bounded progress note below). Profile and owned-series page adapters and other static numeric consumers are not thereby migrated. The remaining old callers are not supported by current API evidence. Conversely, the AEDAR acquisition client in `app/src/fiche/content/aedarApiClient.ts` uses `/api/resources/read-batch` and is a retained working path; do not call it broken based on old backend-only notes. No live HTTP/browser or deployed-frontend verification was performed for this inventory.

## Bounded worker-batch progress — ordinary scalar consumers

The unmerged #627 scalar batch replaces retired scalar-cohort routes with producer catalogue validation plus bounded `POST /api/resources/read-batch` reads in `scalarCohort.ts`. It covers the selected ordinary scalar on the indicator page, the selected ordinary scalar overlay on the standalone map, and registered ordinary scalar cohorts on the eligible non-theme-acquisition fiche path. The initial fiche facts and resolved default comparisons share one read-batch snapshot within the API's 12-item limit; a repeated resource is paired by its unique batch item ID. If that paired batch fails, an independent facts-only read can preserve API-authoritative numeric facts while comparison ranks remain cleared and retryable; this recovery does not claim a shared snapshot. Changing the fiche comparison reads comparison data only, retaining acquired facts; a failed rank read clears ranks and offers a nonblocking retry while numeric facts remain visible, and stale-scope responses cannot restore ranks. Empty/singleton selections produce no rank. The public producer catalogue can include non-theme resources with an empty `theme_id`; scalar requests still strictly bind each scalar declaration to its expected theme. Page/map requests use one resource and preserve commune scope filters or the all-Bretagne map cohort. API-selected values suppress static values while pending/failed. Semantic observations retain native status, support/denominator and source/vintage evidence; acquired scalar facts do not repopulate legacy fixed-scope rank fields. Map ranks are separately acquired from the exact selected commune group or producer same-level fixed comparison and are retryable; pending rank responses are invalidated when the selected cohort/layer changes. Targeted mounted/adapter tests cover these seams, retry and stale-response handling.

This is **not** full #627 consumer parity, a change to the acquisition switch default, or evidence of live public-HTTP, deployment, publication, p95, or full-site cutover. Profiles, distributions, owned series, named references, remaining indicator-page/table/map consumers, active theme facts/comparisons, and other fiche/static readers retain their separate dispositions below. Keep every #627/#587 checklist item open until its full acceptance evidence exists.
