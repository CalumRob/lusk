Recompute as documented in the broader inventory; never hand-maintain these counts.

- This checkout's frontend is not fully migrated to the current API contract. `TerritoireView.vue` still requests `/themes/{theme}/facts` and old comparison paths; indicator-page adapters still name retired scalar/profile/series/indicator route families. Current API evidence does not validate those callers. Conversely, the AEDAR acquisition client in `app/src/fiche/content/aedarApiClient.ts` uses `/api/resources/read-batch` and is a retained working path; do not call it broken based on old backend-only notes. No live HTTP/browser verification was performed for this inventory.
