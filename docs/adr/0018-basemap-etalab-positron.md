# Basemap is Etalab positron (vector, ODbL) — not CARTO Voyager (raster, enterprise-only)

ADR-0008 left the basemap as **CARTO Voyager** raster tiles from `basemaps.cartocdn.com`, "matching the legacy app". That choice predates CARTO's 2026 terms change: CARTO Basemaps are now available **only with an Enterprise license** — no free tier, no basemap-only pricing, free use only for CARTO grant recipients (docs.carto.com/faqs/carto-basemaps; the basemap-styles repo LICENSE.md states tile access is "restricted to CARTO enterprise customers and Non-Profit GRANTS only and is not available for free public use"). Lusk's data identity is open data — Licence Ouverte 2.0 bulk, ODbL for the accepted OSM-derived layers (ADR-0001) — and the app's map had been hitting a tile CDN whose terms no longer matched that identity.

**Decision (user, 2026-08-10):** the map's basemap is **Etalab's OpenMapTiles positron** — vector tiles from `openmaptiles.geo.data.gouv.fr` (OSM-derived, ODbL), served **free with no API key and no published rate limit**. The style is **vendored locally** (`app/public/positron-nolabels.json`) with the 14 symbol layers stripped — no labels, the `voyager_nolabels` look preserved — so MapLibre fetches no glyphs/sprites. The OSM attribution ("© Contributeurs OpenStreetMap", the ODbL requirement) comes from the source's TileJSON (`planet-vector.json`) and is rendered by MapLibre's default compact attribution control (the ⓘ). The map's own overlay layers (GeoJSON masks per ADR-0008, theme choropleths) are unchanged.

**Considered options:** (1) keep CARTO Voyager — rejected: enterprise-license-only terms no longer fit an open-data observatory, and the raster CDN stays a licensing liability; (2) IGN Géoplateforme vector tiles (PLAN.IGN, Licence Ouverte) — rejected after a real trial: slow and visually overcluttered (user's words); (3) **Etalab OpenMapTiles positron — chosen**: free, keyless, lightweight vector tiles, ODbL already accepted by the product (ADR-0001), and the light unlabeled style matches the old look; (4) self-host tiles from OSM extracts — not needed yet, stays the escape hatch.

**Consequences:** the app ships one vendored style JSON (36 layers, no symbol layers) under `app/public/`; the map never talks to the CARTO CDN; attribution is ODbL-correct and visible through the compact control; there is **no SLA** on Etalab's tile service (best-effort public service — acceptable for an observatory, not a 24/7 commercial product); if the service's terms ever change or it degrades, the switch is one style URL — self-hosting from the Geofabrik extracts the pipeline already pulls (ADR-0001) is the fallback. CARTO-PE (the IGN Admin Express WFS layer names in the pipeline) is unrelated and unchanged.
