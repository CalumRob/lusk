# Le rang — ordinal directionnel dans le groupe de comparaison, percentiles retirés du payload

The fiche promised "rank-in-context" on every indicator, delivered as a percentile chip — `formaterRang` renders `rang_epci` ∈ [0,1] as « P25 de l'EPCI ». Grilling (2026-08-07, audit Partie II items 30–31) found three defects: **(1) direction-blind** — the chip is the raw percentile of the value, so Rennes' `iso_alimentation` = 0 % (the best possible outcome: no building without food access) renders « P1 de l'EPCI » (the worst possible reading); **(2) scale-hiding** — a percentile over a small group is meaningless (« P40 de l'EPCI » over 8 communes) and the chip never shows the group's size; **(3) false affordance** — the chip reads as a button, but the comparison it implies (the group ranked) does not exist as a page.

**Decision (user, 2026-08-07):** the rank-in-context becomes a **direction-aware flat ordinal within the nearest policy-relevant comparison group** — the EPCI for communes (the intercommunalité is where policy levers live; its communes can be few, and that honesty is kept by always showing the group size), the département for EPCIs — rendered **« Xᵉ / Y dans l'EPCI »** (1er/41 · 4e/8). **1 = best**: each indicator's desirability direction is known at computation time in the pipeline (low-is-good keys — `iso_*`, part de passoires, chômage — count from the lowest value; high-is-good keys from the highest); ties use competition ranking (ex æquo share the rank, next rank skips — 1, 1, 3). **Percentiles leave the payload entirely** — verified display-only (the map's colours and seuils are value-based; no other consumer of `rang_*`): the pipeline publishes the ordinal rank + group size per comparison level, honoring the app-renders / pipeline-computes seam. For share-type indicators the figure also carries a quiet parent-value line — « dans l'EPCI : X % » — looked up app-side from the parent rows that already exist in the payload (no contract change). A **Classement page** — one page per indicator, the comparison group ranked, filterable by DEP / EPCI — is locked as a long-term feature; until it ships, the chip is a plain label, never a button.

**Considered options:** (1) keep the percentile — rejected: direction-blind (the Rennes P1 inversion is a live bug on the flagship theme), scale-hiding, statistically weak over small EPCI groups; (2) larger primary groups (département ~100–250, région ~1 200) — rejected for the *primary* rank: statistically stronger but less policy-relevant than the intercommunalité, and département/région fiches would lose any rank (n = 4 départements is meaningless); (3) « top X % » language — rejected: still hides the group size and the direction; (4) derive the ordinal in the app from the percentile (`round(p × n)`) — rejected: the app would start computing (violating the stated seam), ties/NA edges get sloppy, and the direction registry would live in two places — the pipeline knows each indicator's direction and already handles ties (`percentile_par_groupe`); (5) publish both percentile and ordinal — rejected: the percentile has no remaining consumer once the chip is ordinal ("no need to ship percentiles at all anymore" — user, 2026-08-07).

**Consequences:** the payload contract changes — the `rang_epci` / `rang_dep` / `rang_reg` percentile columns (and their [0,1] validator) leave the `indicateurs` table, replaced by a direction-aware ordinal (integer position, 1 = best) and a group-size column per comparison level. Touches: R `compute_ranks` / `percentile_par_groupe` plus a per-key direction declaration in each theme descriptor (documented in Méthodes); app `types.ts` / `validate.ts` / `selectors.ts` (`formaterRang` becomes an ordinal formatter with French ordinals — 1er, 2e, 3e…) / `IndicatorFigure.vue`; fixtures and the payload contract/validate/selectors tests. The Rennes inversion is fixed by construction — 1er is always good. The map is unaffected (value-based). The Classement page later reuses the published ranks. `CONTEXT.md` gains a « Rang » entry; this ADR records the semantics it points to.
