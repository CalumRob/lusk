## 1. Injected payload test-loader defaults are demand-driven (merged union reconciled)

`usePayload`'s default start request is now `attendre` for **every** consumer, injected test loaders included; only the no-wait-set form retains the historical full-set default (`app/src/payload/usePayload.ts`). The previous injected-loader full-store eager start was test-only — production was already demand-driven — and its removal revealed a real production gap, resolved by the owner decision recorded here:

- **Standalone carte theme tabs (owner decision, 2026-11-02).** CarteView's theme tab bar (`themesPresent`), `?theme=` presence gate and map rank page descriptors read the six themes' `indicateurs_*`/`histoires_*`/`theme_*` sections — which no production surface loads since #868/#871 — so a cold `/carte` visit had lost its tab bar (the implicit eager default masked this). The carte now requests exactly those sections through an explicit `demarrer` (`FICHIERS_DEMARRAGE_CARTE`), carte-only; the wait-set remains the render gate and the fiche stays API-only. The retained ADR-0019 tab bar is restored in production, and the mounted carte/map specs pass demand-driven.
- **Store-seam regressions pin both defaults** (`payload-store.spec.ts`): a narrow wait-set with an injected loader starts only its files (plus the standard `territoires-metadata` warm rule) and leaves unstarted sections at their honest empty state; the no-wait-set form still starts the full set. Tests whose genuinely-needed background files were previously implicit now request them explicitly, each with a comment naming its subject (large-theme ingestion, pending/scoped background failures, presence-drift chains, scoped retry). One previously-vacuous test (background transport failure) is genuinely exercised again. No test was blindly made eager; no acquisition architecture changed. The shared-store seam itself (`creerMagasinPayload`, staged starts, presence transitions, recovery) keeps its dedicated suites (`payload-store-overlap`, `payload-store-transitions`) and the production-path `indicator-read-model-route` spec, all green.
