## Enumeration and coverage check

Enumeration method: Python stdlib JSON parsing of all six `pipeline/inst/extdata/theme-metadata/theme_*.json` files; union is represented by each theme-scoped `indicator_keys` member (no grep-derived IDs). For each member, contract class is exact membership in `scalar_contracts`, `profile_contracts`, `owned_series_routes`, `observed_collection_contracts`, and `distribution_contracts`; the primary source ID is `sources[ID]`, and declared input-source lists are taken from `indicator_pages[ID].sources` where present. Mobility legacy exclusion is the finite explicit ID set shown below. AEDAR measures are separately enumerated from the producer formula documented below. Readers are evidence references, not traffic claims.

Validation on the pinned source: 6 metadata files; 62 theme-scoped indicator entries; 62 unique theme/ID pairs; 29 excluded and 33 retained. Every source `(theme, indicator_key)` pair was compared with the table pair set; duplicate, missing, extra, or unclassified members fail the source inventory check. Contract-membership counts are 30 scalar, 9 profile, 4 owned-series, 2 observed-collection, and 1 distribution declarations; overlaps are intentional (for example `prix_m2` has scalar and owned-series declarations). Each class count was independently recomputed from its source map. Runtime membership is validated independently by `api/tests/test_resource_catalogue.py` against producer declarations.

`source_records` additionally enumerates source identities per theme; the primary `source_id` is looked up by exact indicator ID in `sources`, not guessed from a name. Declared input-source lists are preserved separately (the B316 ratio uses both `bpe_b316` and `bornes-recharges`). The three special cases proved outside those five metadata maps are enumerated below from publisher declarations: `structure_age` profile, `raccordement_reference` named-reference alias, and `subventions_annuelles` owner series. No unaccounted source-declared member is silently promoted. For the owner-retained B316 ratio, the source record currently disagrees with the authoritative Mobility input manifest (metadata says BPE 2024; manifest/reader pin BPE25/2025). This is a provenance-descriptor consistency correction for implementation, not a product-scope uncertainty. No runtime package, R startup, database, or source-data scan was used.
