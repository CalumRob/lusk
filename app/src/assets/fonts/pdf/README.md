# PDF font assets

Generated by `python scripts/derive-pdf-fonts.py` from the app's own
`@fontsource-variable` packages (OFL-1.1). Each TTF is a static instance of
the family/weight/style the Cahier document embeds; `manifest.json` records
the source file, byte size and SHA-256. The `*-LICENSE.txt` files are copies
of the upstream package licences. Do not hand-edit the binaries.
